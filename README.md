Application web intelligente développée avec Python et Flask pour assister les professionnels de l’audit dans la génération de documents.

L’application combine des techniques de traitement automatique des documents, OCR, recherche sémantique et intelligence artificielle générative afin d’automatiser certaines tâches du processus d’audit.
